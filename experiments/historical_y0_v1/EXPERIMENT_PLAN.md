# HISTORICAL Y0 BASELINE V1: зафиксированный план

## Вход и предмет прогноза

- Источник: сохранённый Sina JSONP, полученный через AKShare.
- Инструмент: `Y0`, дневной основной непрерывный контракт на соевое масло.
- Рабочая копия: CSV передаётся CLI явно; источник проверяется против строки `Y0` в `DOWNLOAD_MANIFEST.csv` и SHA-256 исходного payload.
- Период supervised samples: с `2015-01-01` по `2025-12-31`; данные до 2015 года разрешены только для causal warm-up. Даты 2026 года не участвуют ни в sample, ни в target.
- Цена: именованное поле `close`; `settlement`, volume и open interest не являются признаками и не подменяют close.
- Target: `log(Close_next_published_session / Close_t)`. Момент прогноза — после закрытия сессии t и публикации выбранных дневных полей. Это EOD-исследование, не торговая стратегия.

## Качество и сессии

- Проверяются дата, сортировка, дубликаты, NaN/Inf, положительность close, OHLC, скачки и годовое покрытие.
- Полные дубликаты разрешено схлопнуть с записью; конфликтующие дубликаты останавливают эксперимент. Invalid OHLC bars исключаются вместе с переходами до/через них; нет интерполяции или заполнения.
- Target и все lag/rolling-окна используют только соседние строки исходной отсортированной последовательности. После фильтра invalid bar последовательность не сжимается для построения target.
- Локального независимого календаря DCE нет. Поэтому результат использует последовательность опубликованных дневных баров как указание следующей опубликованной сессии, но не утверждает независимо подтверждённую полноту календаря и не называет календарные разрывы пропусками.

## Фиксированные признаки

Ровно 10 причинных признаков: `ret_1`, `ret_3`, `ret_5`, `ret_10`, `ret_20`, `volatility_5`, `volatility_20`, `distance_sma20`, `weekday_sin`, `weekday_cos`.

Returns: натуральный логарифм отношения close. Volatility — `numpy.std(..., ddof=0)` последних 5/20 односессионных returns. `distance_sma20 = log(close_t / mean(close_(t-19)...close_t))`. Для дня недели `w = feature_date.weekday()` (понедельник 0), `sin(2*pi*w/5)` и `cos(2*pi*w/5)`. Нужно 21 последовательный валидный исходный бар до t включительно; centered windows и заполнение запрещены.

## Split, модели и метрика выбора

- train: 2015-01-01..2021-12-31;
- validation: 2022-01-01..2023-12-31;
- test: 2024-01-01..2025-12-31.

Feature и target обязаны попасть в один split. Alpha grid Ridge: `0.01, 0.1, 1, 10, 100`. Для выбора alpha: `StandardScaler` и Ridge fit только на train, primary metric — validation MAE log-return. При равенстве выбирается меньший alpha. Затем scaler+Ridge переобучаются на train+validation и test оценивается ровно один раз. Baseline — всегда нулевой log-return.

## Интерпретация

Считаются MAE/RMSE log-return, MAE цены, directional accuracy с долями нулей, MAE skill и paired moving-block bootstrap (20 последовательных test-записей, 2000 повторов, seed `20260930`). Continuous-series методика выбора/ролла/корректировки не опубликована в локальных материалах и фиксируется как `UNKNOWN`; результат не доказывает point-in-time воспроизводимость, прогноз JO_165951/spot/farm-gate или пригодность для торговли.
